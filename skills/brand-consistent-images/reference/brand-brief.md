# Brand brief template

Fill this once per brand from its website, guidelines or best past posts. With the Wireflow app it becomes the `brand_brief` input on every run. Without Wireflow, paste the prompt prefix at the top of every image prompt in any tool that takes reference images. Either way, the same brief on every image is what keeps a set consistent.

## Visual identity

- **Brand**: `<name>`, `<what it sells, in five words>`.
- **Palette**: `<name> <hex>`, `<name> <hex>`, `<name> <hex>`, `<name> <hex>` (main color first).
- **Light**: `<soft daylight / warm low evening light / hard studio flash>`.
- **Surfaces and materials**: `<linen, oak, stone, ceramic, pastel paper, brushed steel>`.
- **Composition**: `<one hero object with lots of negative space / busy lived-in scenes>`.
- **People**: `<none / hands only / everyday adults, natural poses>`.
- **Mood**: `<three words, e.g. calm, unhurried, warm>`.
- **Avoid**: `<neon, glossy plastic, heavy filters, stock-photo smiles, clutter>`.

## Worked example (the invented brand in this skill's examples)

> Tavrin Candle Co., hand-poured candles. Palette: oxblood #5B2A2A, amber #B8742A, oak #C9A36B, cream #F4EDE1, charcoal #2B2B2B. Light: warm, low evening light with soft shadows. Surfaces: natural stone, oak, linen, ceramic. People: none. Mood: calm, unhurried, uncluttered. Avoid: neon, glossy plastic, busy backgrounds, extra text.

## Prompt prefix (for tools without the app)

> On-brand image for `<brand>`. Copy the logo from the reference exactly, same shapes, letters and colors. Keep the product exactly as photographed. Palette: `<palette words>`. `<light>` light, `<surfaces>`, `<composition>`, `<people rule>`. No other logos, no words except the ones quoted below. Full bleed, no border.

## Consistency checks for a set

- Same brief, word for word, on every image.
- Same reference images in the same slots on every run (logo first).
- Same camera distance for the same kind of image.
- Lay the set out side by side; redo the odd one out rather than the whole set.
